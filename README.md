## 🌟 Описание проекта

**Local Cloud File Drop** — это домашний аналог технологии Apple AirDrop, работающий на любых операционных системах (Android, iOS, Windows, macOS, Linux).

Сервис решает частую бытовую проблему: родителям нужно быстро скинуть фотографии с отпуска или документы со смартфона на компьютер (или наоборот) без необходимости подключать провода, регистрироваться в облаках или сжимать качество через мессенджеры.

### Ключевые возможности:
- 📱 **Мгновенный вход по QR-коду**: приложение автоматически определяет локальный IP компьютера в сети роутера и генерирует QR-код. Достаточно навести камеру любого телефона.
- 🚀 **Максимальная скорость домашнего Wi-Fi**: передача идет напрямую между устройствами внутри квартиры (300–800 Мбит/с), не расходуя мобильный трафик и не завися от скорости провайдера.
- 📂 **Drag & Drop**: простое перетаскивание файлов мышкой в окно браузера на ПК.
- 🔒 **100% приватность**: файлы физически не покидают пределы квартиры и не отправляются на сервера сторонних компаний.

---

## 🛠 Стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, Python Multipart Streaming
- **Сетевое ядро**: Low-level UDP Socket LAN Auto-Discovery, Pillow + qrcode (динамическая генерация base64 Data-URI)
- **Frontend**: HTML5, Tailwind CSS, Drag-and-Drop API, XMLHttpRequest с отслеживанием прогресса загрузки

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
В консоли и на веб-странице отобразится адрес локальной сети и QR-код для телефона.

### Запуск вручную:
```bash
pip install -r requirements.txt
python main.py
```
Перейдите с любого устройства в доме по адресу:
`http://<IP_КОМПЬЮТЕРА>:8005`

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Файлообменник между смартфонами и компьютером должен функционировать по принципу сетевой розетки — быть доступным в любой момент:

1. **Круглосуточный домашний файловый хаб (Home NAS)**:
   - Если сервер работает 24/7, мама может в любой момент перед сном скинуть фотографии с телефона в архив или скачать рецепт, не включая тяжелый рабочий ПК.
2. **Экономия семейного бюджета на облачных подписках**:
   - Google Диск, Яндекс Диск и iCloud требуют ежемесячной оплаты за расширение памяти (от 200 ГБ до 2 ТБ). Домашний сервер с жестким диском дает терабайты бесплатного семейного хранилища навсегда.
3. **Автоматическая синхронизация медиатеки по расписанию**:
   - Сервер 24/7 может в фоновом режиме по ночам принимать резервные копии снимков с телефонов всей семьи, освобождая память смартфонов.
